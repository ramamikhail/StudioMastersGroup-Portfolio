# Studio Masters Group — Portfolio

## Creative direction · Technical development · Practical execution

Studio Masters Group (SMG) brings together work across publishing, design, software, and interactive media.

This repository provides a curated, public-facing overview of selected projects, capabilities, and technical direction. It serves as an entry point for prospective clients, collaborators, and others interested in our work.

⸻

Purpose

* Present selected projects across the SMG organization.
* Explain the purpose, development status, and contributions behind each project.
* Connect creative work with the technical systems that support it.
* Provide clear paths to related portfolios and public repositories.

⸻

Areas of Work

Area	Focus
Publishing & Storytelling	Original writing, editorial development, worldbuilding, and publishing projects
Design & Creative Direction	Brand identity, visual communication, and creative production
Software & Digital Systems	Applications, workflow tools, and supporting software
Games & Interactive Media	Game development, interactive experiences, and production studies
Fabrication & Prototyping	3D modeling, digital fabrication, and physical product exploration

These areas reflect the organization’s working scope. Individual project entries identify what has been completed, what is in development, and what remains exploratory.

⸻

Portfolio Contents

As entries are added, this repository will include:

* Project summaries and selected visuals.
* The responsible company or creative practice.
* Development status and available outcomes.
* Relevant tools and technology stacks.
* Links to approved public repositories and project pages.

⸻

Scope & Publication Boundaries

This repository contains material prepared for public presentation.

Internal infrastructure, private documentation, confidential information, experimental code, and unreleased creative assets are maintained separately.

A project summary or repository link does not make its underlying source code, assets, or intellectual property available for reuse. Refer to each project’s license and accompanying notices for applicable terms.
